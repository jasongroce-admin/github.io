Three steps to open it.

  1. Download the ZIP.

    Save the package to your computer.

  2. Choose Extract All.

    Right-click the ZIP, choose Extract All, then open the extracted folder.

  3. Open Start groce-eye.cmd.

    Double-click the launcher. Your browser opens automatically. Keep its server window open while exploring.

Close the server window to stop. Windows may show a warning for downloaded scripts; the package is unsigned and its files are readable. Organization policies may prevent it from running.

What the local connections add.

  • Aircraft: regional ADSB.lol observations. The server also includes an optional OpenSky endpoint for personal, noncommercial use, with a limited anonymous allowance.
  • Satellites: CelesTrak space stations and a larger active catalog. Positions are estimates calculated from dated orbital elements.
  • Cameras: Fintraffic public road-weather cameras in Finland, with provider images and refresh times.

Free providers can be unavailable, rate limited, delayed, or incomplete. This package helps the browser make supported requests; it does not remove provider limits or unlock paid layers.

Use aircraft feeds for personal exploration under the ADSB.lol terms and OpenSky terms. ADSB.lol asks commercial users to contact them; OpenSky restricts its free API to noncommercial use.

The server listens only on your computer. It contacts a fixed list of public providers and accepts no API keys. Map tiles and camera images may load directly from their providers. Internet requests disclose your public IP to those providers.

Using a phone or another computer?

Open the browser viewer. This launcher is specifically for Windows. No Pinokio installation or additional runtime is needed.

The original upstream project is separate and may support your own provider keys. The free groce-eye package does not install that app or configure paid connections.
