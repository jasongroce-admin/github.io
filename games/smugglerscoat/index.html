About Smuggler’s Coat

This is a modern HTML5 remake of the legendary 1984 text-based trading game Drug Wars (later known as Dope Wars). The original was created by high-school student John E. Dell for IBM PC DOS. It spread to BBS door games, graphing calculators, Palm OS (1999), and Java ME feature phones in the early 2000s.

Original Creator: John E. Dell, 1984
Inspired ports: Palm OS • Java ME • TI-82 calculators • Windows Beermat edition
