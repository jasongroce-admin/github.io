JR's Plumbing — static site (GitHub Pages ready)

This folder is the playable game. No install, no server-side code.

Put it on your site
-------------------
1. Unzip.
2. Upload everything inside this folder to a directory on your site,
   for example:  games/jrs-plumbing/
3. Visit:  https://YOUR-SITE/games/jrs-plumbing/

GitHub Pages: drop these files in /docs (project site) or the repo root
(user site), commit, and enable Pages. The .nojekyll file is already included.

Play on your computer
---------------------
Unzip, then open index.html from any static host. Double-clicking the file
directly (file://) often fails because the browser blocks the game scripts.

High score is saved in that browser on that site (localStorage).
